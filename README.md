# TravelDiary v1.0

这是 Android 旅行日记工程。

功能：
- 旅行列表 / 新建旅行
- 同行人员
- 交通
- 吃穿住行费用
- 穿搭计划
- 相册记录
- 经典照片模块入口
- 每日旅行日记
- Room 本地数据保存
- GitHub Actions 自动生成 APK

使用：
1. 解压 ZIP。
2. 将解压后的全部内容上传到 GitHub 仓库根目录。
3. GitHub -> Actions -> Build TravelDiary APK -> Run workflow。
4. 构建完成后，从 Artifacts 下载 APK。
